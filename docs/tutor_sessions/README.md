# Tutor Sessions

Append-only log of `/tutor` sessions (see `skills/tutor/SKILL.md`).
One file per session, named `<YYYY-MM-DD>-<persona-slug>-<topic-slug>.md`,
written once at session end and never edited afterward. This is the audit
trail; `docs/mastery.md` is the current-state lookup the skill actually reads.
